Independent VLC-powered Android development build, version 0.2.0, ARM64, Android 9 or newer.

- Apple clear and LastWave depth modes, with adjustable convex refraction, edge dispersion, frosting and highlights.
- Responsive YouTube-style player controls, hold for 2×, captions, original-resolution reporting, zoom and local seek previews.
- Continuously animated Anatomy SVG flywheel and lamps, with reduced-motion support.
- Local library, playlists, bookmarks, 10-band equalizer and native LibVLC 3.7.6 engine.

Build, package/signature checks and browser UI checks passed. Android device installation, native decoding, native lens execution, casting, PiP and lifecycle behavior remain untested. Full VLC desktop parity is not claimed. This is not an official VideoLAN release.

The APK retains the 0.1.0 signing certificate. The source ZIP excludes the private signing key. Both release downloads are reconstructed from checked-in transfer parts and verified against SHA-256 before publication.
