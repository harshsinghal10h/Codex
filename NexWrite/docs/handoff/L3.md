`apps/web` is a real React/Vite local demo, using the compiled Rust WASM through
a dedicated Worker. It offers one plain/Markdown source textarea, one original
spacing rule, source counts and explicitly labelled/gated estimates. It is not
the rich editor, offline shell, accounts/backend, collaboration or full M2 web
product. COR-11, INS-02, DOC-01 and DOC-06 move spec → in-progress only.

Committed edits/format changes/Accept/Undo invalidate old results immediately.
Version/format/source checks prevent stale replacements; IME suppresses checks
and actions until composition completes. Pause terminates the Worker; retry
loads the actual engine. Accept history keeps at most 20 snapshots and typing
clears it. At most 20 cards render while the true suggestion total stays visible.
Native textarea input/restored drafts adopt LF; export and Undo preserve that
adopted source. The core independently preserves raw CRLF source coordinates.

Draft storage starts off. Consent enables only owned local keys; opt-out removes
draft/consent, and Clear removes owned settings without erasing current text or
other applications' keys. Invalid/oversized/malformed saved data and denied/quota
storage remain visible failures with memory editing available. There is no
document upload, telemetry, account or network analysis fallback.

Run from NexWrite after activating retained tools:

```sh
just build web
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium just browser-test
just web
```

reuse a cached app when Rust changes, and required toolchain/proxy/CA settings

executable. Development processes are temporary; do not stop unrelated listeners
or advertise a localhost link as a published app.
