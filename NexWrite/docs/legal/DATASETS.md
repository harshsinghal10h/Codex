# Dataset license gate

No external training corpus, dictionary, model weights or evaluation dataset has been imported. No model training or AI-likelihood claim exists in Task 0. Test strings for the spacing rule and Unicode boundaries are authored for this project. Model packs must not be committed.

Default future path: original annotation and synthetic error injection on demonstrably public-domain/CC0 or compatible permissive text. Research-only licenses do not imply commercial permission. Reference-product output is prohibited for training, distillation and testing. Separate corpus, dictionary, annotation and model licenses; attribution and source URLs must survive packaging.

Before use, add a row containing dataset/version/checksum; source URL/retrieval date; author; exact license text/reference; commercial/redistribution/derivative/privacy constraints; consent/PII assessment; allowed purpose; reviewer/disposition; and removal procedure. Model cards must record provenance, metrics, limitations and fairness slices (dialect, genre, non-native writer). No row is approved by omission.

SP-10 (UNK-SP-10) and dataset-contamination risk UNK-RISK-03 remain open for M1/ML work. A public download or an OSS code license does not establish the dataset's license.
