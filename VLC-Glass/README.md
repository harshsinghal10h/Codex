# VLC Glass for Android

An independent media player powered by LibVLC 3.7.6, with **Apple clear** and **LastWave depth** glass appearances. Includes a local media library, playlists, advanced player controls, live-video lens support on Android 13+, and animated Anatomy artwork.

**Android 9 or newer, arm64 devices. Development release.**

Change the glass finish through **Settings → Visual & appearance → Liquid glass → Emulate mode**. That screen also has depth, prismatic edge, frosting, highlight, contrast, SVG loop and reduced-motion settings.

The player includes speed controls, hold for 2×, double-tap seeking, subtitles, tracks and delays, bookmarks, A–B looping, a queue, equalizer, sleep timer, cast selection, and picture in picture. Native device behavior still requires verification. This is an independent development build and does not implement every VLC desktop feature.

The complete source and notices are included. Signing keys are excluded. See the source README and QA record for build instructions and exact feature boundaries.
