# Engineering agent guidance

Keep documented claims limited to code and test evidence. Prioritize Keycloak OIDC and tenant isolation, then Nextcloud file operations and CalDAV integration, then native Android/iOS/macOS user journeys. Never invent performance numbers, security certifications, provider permissions or signed platform packages. Test cross-tenant access for every new API route. Do not commit secret credentials, compiled binaries or unreviewed AGPL/enterprise assets.
